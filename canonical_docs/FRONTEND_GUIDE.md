# FRONTEND_GUIDE.md

## Mandatory UI Rules

These rules override default frontend design preferences and general styling heuristics.

- Never use pill-shaped UI.
- Prefer squircle styling wherever feasible.
- Use card-based layout as the default layout pattern.
- Never use visually nested card-inside-card design.

## Enforcement Notes

- Never use capsule, stadium, or fully pill-rounded buttons, inputs, tabs, chips, or badges.
- Prefer rounded-rectangle or squircle components instead.
- If additional grouping is needed inside a card, use spacing, dividers, typography, or subtle background separation.
- Never create a second bordered or shadowed card surface inside an existing card.

## Priority

If general design guidance conflicts with this file, this file takes precedence.
